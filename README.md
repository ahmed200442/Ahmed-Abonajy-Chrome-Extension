# Ahmed Abonajy Chrome Extension

إضافة **Ahmed Abonajy** لمتصفح Chrome وMicrosoft Edge — الإصدار v0.4.0.

## التثبيت على الكمبيوتر
1. نزّل ملف ZIP الخاص بالإضافة وفك ضغطه في مجلد ثابت.
2. افتح `chrome://extensions` في Chrome أو `edge://extensions` في Edge.
3. فعّل **Developer mode / وضع المطوّر**.
4. اضغط **Load unpacked / تحميل إضافة غير محزّمة**.
5. اختر المجلد الذي يحتوي على ملف `manifest.json`.

## ملاحظة مهمة
هذا المستودع عام، لكن ملف ZIP القابل للتثبيت لم يُرفع إلى GitHub بعد. بعد رفع الملف من خلال صفحة **Releases** يمكن مشاركة رابط تنزيل عام مباشر.

## التوافق
التثبيت بهذه الطريقة يتطلب متصفحًا على الكمبيوتر؛ Chrome على Android لا يدعم خيار Load unpacked.
